# Création de personnage — magie et bonus raciaux (2014)

Le nombre de sorts préparés dépend désormais des caractéristiques **finales** du personnage, après application des bonus d'espèce et de sous-espèce, plutôt que des scores de base. Ceci concerne le Magicien (Intelligence), le Clerc et le Druide (Sagesse). Les contrôles de fin de création et les compteurs affichés utilisent la même valeur.

La progression à l'étape suivante est également bloquée si une sous-espèce obligatoire n'est pas choisie.

Le script `node scripts/test-spellcasting-racial-bonuses-2014.mjs` vérifie les effets pour un Gnome magicien, un Elfe des bois druide et un Humain clerc.

Limites : le catalogue de sorts reste partiel, la compilation Next complète et les tests navigateur avec Supabase restent nécessaires.
