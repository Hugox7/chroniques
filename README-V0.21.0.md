# V0.21.0 — Retrait de l’ancien configurateur d’avatars

- Suppression du composant avatar-builder et des ressources graphiques correspondantes.
- Création : champ libre de description physique, sans générateur.
- Fiche : description modifiable ; les anciennes configurations CD_AVATAR_V1 sont conservées dans la base, sans être affichées comme du texte.
- Aucun appel IA, paiement ou génération de portraits n’est encore implémenté.
- Les données existantes en base ne sont pas supprimées.
- Le script historique d’audit d’assets avatar n’est plus applicable à cette version.
