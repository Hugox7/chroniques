# V0.19.33 — Neuf espèces pour le portrait

- Sélecteur d’espèce étendu aux neuf espèces du Manuel des Joueurs D&D 5e (2014).
- Dessins SVG différenciés : oreilles elfiques, oreilles courtes, cornes de tieffelin/drakéide, défenses de demi-orc, écailles de drakéide, nez de gnome, barbe de nain.
- Les calques PNG humains sont conservés et ne sont pas réutilisés pour les espèces non humaines : le rendu SVG sert de solution temporaire explicite.
- Le choix de l’espèce du portrait n’altère pas les caractéristiques de la fiche de personnage.
- Pas de migration SQL.

Limites : ces portraits restent stylisés, et ne représentent pas encore fidèlement toutes les anatomies ni les portraits semi-réalistes visés. Build/typecheck non exécutés (dépendances absentes).
