# V0.20.7 — Ajouts décoratifs sur portraits illustrés

- Deux portraits WebP restent des images fixes au format 2:3, sans déformation.
- Possibilité de superposer un diadème, une amulette ou une cicatrice au portrait illustré humain. Les réglages correspondants restent actifs en mode illustré.
- Export PNG reproduit désormais l’illustration ET sa superposition SVG.
- IDs SVG uniques entre portraits pour éviter les conflits de dégradés.
- Aucun changement de base de données : sérialisation CD_AVATAR_V1 conservée.

**Limite :** ces superpositions sont décoratives et leur placement est approximatif. Il ne s’agit PAS de véritables cheveux, visages, tenues ou espèces illustrés interchangeables. Le rendu SVG des huit autres espèces reste provisoire.

Contrôles statiques et actifs exécutés ; compilation Next et test navigateur non effectués.
