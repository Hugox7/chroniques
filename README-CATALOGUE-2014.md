# Catalogue structuré 2014 — étape intermédiaire

- Le référentiel de noms de sorts existants est désormais dédoublonné et enrichi avec niveau (0 ou 1) et classes associées.
- Dans le créateur, un avertissement non bloquant apparaît lorsqu’un nom reconnu semble associé à une autre classe ou à un autre niveau.
- Les noms inconnus restent autorisés : ce référentiel **n’est pas exhaustif**, et les listes de classes sont limitées aux suggestions déjà présentes. Les avertissements ne sont pas une preuve d’illégalité du choix.
- Les données sont locales, sans migration Supabase. Aucun texte descriptif protégé n’a été copié.
- Vérification isolée du module et tests ciblés, sans prétendre à une compilation Next.js globale.
