# V0.19.26 — Variantes de teints sur calques PNG

- Cinq bases de visage PNG transparentes pour les cinq teints déjà proposés dans l’interface.
- Les variantes gardent les mêmes dimensions et points d’ancrage.
- L’aperçu en mode calques reste actif lors du changement de teint pour les humains compatibles.
- Les zones de peau sont recolorées en conservant une partie des ombres ; texture de grain très discrète.
- Pas de migration SQL.

**Limites :** les oreilles et le cou sont inclus dans le même asset ; les tenues et cheveux restent stylisés. Il ne s’agit pas encore de calques semi-réalistes peints. Build Next.js non vérifié sans dépendances installées.
