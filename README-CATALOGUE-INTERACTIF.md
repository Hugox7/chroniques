# Création niveau 1 — catalogue interactif (2014)

- Sélection filtrée par classe et niveau, recherche locale, exclusion des noms déjà choisis.
- Saisie libre conservée pour les sorts de campagne : catalogue non exhaustif.
- Changement d’un sort du grimoire du magicien : la préparation est réinitialisée afin d’éviter une sélection périmée.
- Les sorts divins préparés utilisent la même interface.
- Aucun changement de schéma Supabase.

## Limites
Le catalogue actuel est partiel et ne permet pas d'affirmer que toutes les options PHB 2014 sont prises en charge. La compilation globale et les tests navigateur doivent être exécutés dans un environnement avec dépendances installées.
