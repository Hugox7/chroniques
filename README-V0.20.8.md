# V0.20.8 — Passage des illustrations aux portraits éditables

- Nouveau bouton « Créer une version personnalisable de ce portrait » depuis les deux illustrations humaines.
- Conserve le portrait choisi comme référence, crée une interprétation modifiable en calques, avec coiffure et tenue de départ adaptées.
- La conversion ne prétend pas modifier les pixels du portrait peint : le rendu est différent.
- Le retour au mode illustration retrouve le portrait peint d’origine.
- Aucune migration SQL.

## Limites

Les deux peintures ne sont pas décomposées en calques compatibles. Les autres espèces utilisent toujours le SVG. La qualité semi-réaliste personnalisable reste un chantier ouvert.
