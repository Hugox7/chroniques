# Dégâts des armes (2014)

Le panneau de jets propose un calcul des dégâts **uniquement après une attaque réussie** avec une arme reconnue de l'inventaire. Les dés physiques peuvent être saisis individuellement ; le lancer numérique reste facultatif. Les critiques doublent les dés, pas les bonus fixes. Les armes polyvalentes peuvent utiliser leur dé à deux mains. Le modificateur de caractéristique et un bonus supplémentaire restent visibles.

**Aucune modification de PV automatique** : le MJ applique les dégâts via le circuit serveur existant, qui gère résistances et immunités. Cela évite une double application involontaire et préserve le jeu hors application.

Limites : pas encore de dégâts additionnels de sorts, de Sneak Attack, de critiques améliorés, de rage, de propriétés magiques ou de choix de cible automatique. La sélection d'une arme ne garantit pas qu'elle soit équipée. La formule polyvalente est limitée aux dés standard SRD.

Validation : tests de règles/progression et contrôle structurel ; compilation Next.js et navigateur à confirmer.
