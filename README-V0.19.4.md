# Chroniques & Dés — V0.19.4 (aperçu)

Progression D&D 5e 2014 monoclassée : les niveaux donnant une amélioration de caractéristiques permettent désormais de répartir deux points (maximum 20) ou d'inscrire un don optionnel. La modification de Constitution recalcule les PV maximum rétroactivement pour les niveaux acquis, y compris le nouveau niveau. Les choix sont enregistrés avec la montée de niveau dans la fiche existante.

Limites : les dons sont consignés en texte libre, sans contrôle de prérequis ni application automatique de leurs effets. Les capacités de classe, sous-classes, sorts connus, multiclassage et ressources ne sont pas entièrement automatisés. Les changements restent enregistrés via la fonction actuelle de sauvegarde de personnage et ne sont pas transactionnels côté serveur. Ne pas tester sur des personnages importants avant sauvegarde.

Pas de nouvelle migration pour cet ajout. Les migrations des versions 0.19.1 et 0.19.2 restent nécessaires. Compilation et typecheck non validés dans cet environnement (dépendances npm absentes). À vérifier avec `npm install`, `npm run typecheck`, `npm run build`.
