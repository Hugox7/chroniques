# Chroniques & Dés — V0.19.5 (aperçu)

Ajout d'un référentiel de rappels de capacités de classe D&D 5e 2014 pour les 12 classes de base. Lors du passage de niveau, la fiche affiche les capacités de classe correspondantes et les ajoute au champ `features` avec la mention du niveau. Les doublons exacts sont évités.

**Important :** ces entrées sont des rappels de progression, et non l'application automatique de leurs effets. Les capacités dépendant de la sous-classe, les choix de sorts, les ressources consommables, les prérequis des dons et le multiclassage restent à développer. Certaines capacités de classe comportent des améliorations à des niveaux intermédiaires qui ne sont pas encore listées. Ne pas utiliser cette version comme référence de règles exhaustive.

Aucune migration supplémentaire. Après installation, exécuter `npm install`, `npm run typecheck` et `npm run build`. Cette version n'a pas été compilée dans cet environnement. Conserver la V0.18.1 stable et ne pas tester les montées de niveau sur des personnages importants.
